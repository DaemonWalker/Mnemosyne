# Mnemosyne 需求说明

> 状态：已与需求方逐轮确认。本文档是实现的唯一需求依据，实现过程中如发现与代码冲突，以本文档为准并回报主对话。

## 1. 产品定位

类 Sublime Text 的轻量文本编辑器。核心指标：**启动快（普通 SSD 机器冷启动 1 秒内）、内存占用小**。

## 2. 技术选型（已定）

| 项 | 决定 |
|---|---|
| UI | C# + WPF，目标框架 **.NET 10**（net10.0-windows） |
| 编辑内核 | Scintilla v5 的 .NET 封装（Scintilla5.NET） |
| Markdown 渲染 | Markdig 解析 → WPF 原生控件渲染（不用 WebView2） |
| 编码探测 | UTF-8 优先 + BOM 识别 + UDE（UtfUnknown） |
| 插件机制 | 约定接口 + 反射加载 `plugins/` 目录下的 dll |
| 配置存储 | JSON 文件，**便携模式**（存 exe 同目录） |
| MVVM | CommunityToolkit.Mvvm |

## 3. 布局（参考 VSCode）

- 左侧活动栏：两个图标按钮 —— 文件列表、搜索。点击切换侧边栏内容，再次点击当前图标收起侧边栏
- 中间：多 Tab 编辑区。**每个文件独立 Tab**（无预览 Tab 模式），**不分栏**，**无 Minimap**
- 底部状态栏：行列号、编码、行尾符（CRLF/LF，可点击转换）、语言模式、缩进宽度、大文件加载进度

## 4. 功能需求

### 4.1 打开
- 打开单个文件、打开文件夹（侧边栏文件树）
- 支持拖拽文件/文件夹到窗口打开
- 支持命令行传文件路径打开；单实例运行（再次启动激活已有窗口并打开新文件）
- 文件菜单保留最近打开的文件/文件夹列表

### 4.2 页内搜索与替换
- 搜索条（Ctrl+F）：支持**大小写敏感**、**全字匹配**、**正则表达式**三个可组合选项
- 高亮全部匹配 + 当前匹配，显示计数，上一个/下一个导航，Esc 关闭
- 替换条（Ctrl+H）：替换、全部替换（**仅页内**）

### 4.3 文件夹内搜索
- 侧边栏搜索面板：关键字 + 大小写/全字/正则选项
- 支持"包含的文件夹"和"排除的文件夹"规则（VSCode 风格 glob，逗号分隔）
- **按需扫描**（不建索引），后台线程执行，可取消，结果增量显示
- 跳过二进制文件
- **不做文件夹级替换**
- 结果按文件分组，显示匹配行上下文，双击跳转到对应位置并高亮

### 4.4 格式化插件
- 接口（如 `ICodeFormatter`）+ 反射加载 `plugins/` 目录
- 内置 JSON、XML、HTML 三个格式化器，以插件形式实现
- 菜单/右键入口：格式化文档

### 4.5 设置
- 设置窗口：默认字体、字号、主题、界面语言、缩进（Tab/空格与宽度）、大文件阈值等
- **连体字不支持**（Scintilla 内核限制，属明确放弃项）

### 4.6 Markdown
- 编辑时语法高亮
- 预览**开新 Tab**（Markdig → WPF 渲染），源文件保存后预览刷新

### 4.7 语法高亮
- Scintilla 全部 Lexer 可用
- 语言选择入口：**弹窗列出全部 Lexer 并提供搜索框**
- 按扩展名自动匹配默认语言

### 4.8 编码
- UTF-8 优先自动检测，BOM 识别，UDE 探测 GBK 等
- 状态栏显示当前编码，可手动切换（切换即按新编码重新加载）

### 4.9 热退出与会话
- 退出时**不提示保存**，未保存修改暂存到本地缓存目录，下次启动自动恢复
- 会话恢复：记住上次打开的 Tab 与文件夹
- 打开的文件被外部修改时提示是否重新加载
- **不做定时自动保存**

### 4.10 主题与语言
- 深色（默认）+ 浅色双主题，语法高亮配色跟随主题
- 界面语言：中文/英文，资源文件实现，设置中切换

### 4.11 编辑体验
- 快捷键体系：Ctrl+O 打开文件、Ctrl+Shift+O 打开文件夹、Ctrl+S 保存、Ctrl+F 搜索、Ctrl+H 替换、Ctrl+Shift+F 文件夹搜索、Ctrl+W 关 Tab、Ctrl+D 选中下一个相同词、Ctrl+, 设置
- Tab：拖拽排序、中键关闭、右键菜单（关闭其他/关闭右侧/在资源管理器中打开）
- 行尾符 CRLF/LF 显示与转换
- 缩进：Tab/空格与宽度设置，按文件自动检测缩进风格
- 自动换行开关、空白字符可视化开关
- **多光标**：开启 Scintilla 多重选择（Ctrl+点击加光标、Alt+拖拽列选择），实现 Ctrl+D
- 文件树右键：新建/重命名/删除文件与文件夹
- 文件树 FileSystemWatcher 监听外部变化自动刷新

### 4.12 大文件加载
- 阈值默认 50MB（可在设置中调整），超过进入大文件加载模式
- 异步分块读取（约 1MB/块），边读边 `AppendText` 追加显示
- 状态栏显示进度条与百分比，提供取消按钮
- 加载期间编辑器只读、语法高亮暂时关闭，加载完成后一次性启用高亮

## 5. 明确不做

连体字、Minimap、编辑器分栏、文件夹级替换、后台索引、定时自动保存、网络更新、命令面板、打印、拼写检查、宏录制、终端集成、Git 集成。
